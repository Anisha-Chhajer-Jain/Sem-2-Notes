Creating Documents in MongoDB

Understanding the Create Operation in CRUD

Now that you understand what CRUD is and why it matters, it is time to begin actual interaction with MongoDB. The first and most fundamental CRUD operation is Create.

If you cannot insert data correctly, you cannot read, update, or delete it.

1. What Does “Create” Mean in MongoDB?

In MongoDB, Create means inserting a new document into a collection. MongoDB works with documents, not rows.

  • The entire document is stored
  • Each document gets a unique identity
  • The document becomes queryable immediately

Before You Insert: MongoDB Shell Basics

1. Entering the MongoDB Shell

mongosh

This connects you to a MongoDB server and places you in a default database.

2. Understanding the Current Database

db

By default, MongoDB connects you to a database named test. Empty databases do not appear in listings.

3. Selecting a Database

use codinggita
MongoDB creates the database only when the first document is inserted. This is called lazy database creation.

4. Verifying Databases

show dbs

2. MongoDB Create Methods

Method Purpose
insertOne() Insert a single document
insertMany() Insert multiple documents

3. Using insertOne()

db.collectionName.insertOne({ document })

Example: Insert Student Document

db.students.insertOne({
  name: "Arjun",
  rollNumber: "12345",
  department: "CSE",
  year: 3,
  coursesEnrolled: ["Data Structures", "Algorithms", "DBMS"],
  age: 22,
  registrationDate: new Date()
});

Insert Result

{
  acknowledged: true,
  insertedId: ObjectId("...")
}

4. The _id Field

Every MongoDB document must have a unique _id field.
  • MongoDB generates it automatically
  • Type is ObjectId
  • Duplicate _id causes insertion failure

5. Using Dates Correctly

Never store dates as strings. Always use new Date(). 
"registrationDate": new Date()

6. Using insertMany()

db.students.insertMany([
  {
    name: "Mahir",
    rollNumber: "12346",
    department: "CSE",
    year: 2,
    coursesEnrolled: ["Mathematics", "DBMS", "OS"],
    age: 21,
    registrationDate: new Date()
  },
  {
    name: "Yashvi",
    rollNumber: "12347",
    department: "CSE",
    year: 2,
    coursesEnrolled: ["Networks", "Algorithms"],
    age: 20,
    registrationDate: new Date()
  }
]);
Beginners should prefer insertOne() and use insertMany() carefully.

7. Common Beginner Mistakes

  • Inconsistent field names
  • Storing numbers as strings
  • Forgetting arrays for multi-value fields

8. When Create Operations Fail

  • Duplicate _id
  • Invalid structure
  • Schema validation rules
MongoDB either inserts the entire document or nothing at all.
