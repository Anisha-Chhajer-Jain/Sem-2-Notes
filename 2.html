Setting Up MongoDB

Local Installation & MongoDB Atlas (Beginner Guide)

1. Choosing Between Local MongoDB and MongoDB Atlas

Option When to Use
Local MongoDB Learning, practice, offline work, exams
MongoDB Atlas Real-world projects, cloud apps, deployment
For beginners, it is recommended to start with local MongoDB. MongoDB Atlas is important when building production-ready applications.

2. Installing MongoDB Locally

A. Windows Installation

Step 1: Download MongoDB

  • Visit MongoDB Community Server website
  • Download the Windows MSI installer

Step 2: Run the Installer

  • Launch the installer
  • Select Complete Installation
  • Keep default settings

Step 3: Install MongoDB as a Service

  • Select Install MongoDB as a Service
  • Choose Network Service user

Step 4: Verify Installation

mongosh

B. macOS Installation

Install Homebrew

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Install MongoDB

brew tap mongodb/brew
brew install mongodb-community

Start MongoDB

brew services start mongodb/brew/mongodb-community

C. Linux Installation (Ubuntu / Debian)

Import MongoDB Key

curl -fsSL https://pgp.mongodb.com/server-7.0.asc | sudo gpg -o /usr/share/keyrings/mongodb-server.gpg --dearmor

Add Repository

echo "deb [ signed-by=/usr/share/keyrings/mongodb-server.gpg ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org.list

Install MongoDB

sudo apt update
sudo apt install -y mongodb-org

Start Service

sudo systemctl start mongod
sudo systemctl enable mongod

3. Using MongoDB Atlas

MongoDB Atlas is a fully managed cloud MongoDB service. No manual server installation is required.

Steps

  • Create an Atlas account
  • Create a free M0 cluster
  • Add IP address and database user

Connect Using MongoDB Shell

mongosh "mongodb+srv://<username>:<password>@cluster0.mongodb.net/"

4. Verify MongoDB Is Working

show dbs

5. Common Beginner Mistakes

  • Not starting MongoDB service
  • Blocking IP in Atlas
  • Using wrong connection string
  • Running mongod manually

6. Summary

You now know how to install MongoDB locally, use MongoDB Atlas, verify the setup, and understand when to use each option.
