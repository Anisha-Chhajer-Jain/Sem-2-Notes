Reading Documents in MongoDB

Basic Read Operations using find() and findOne()

Before you can update or delete data, you must be able to read it correctly. Reads are the foundation of all backend logic.

Inserts are about writing data. Reads are about understanding what you wrote.

1. What Does “Read” Mean in MongoDB?

In MongoDB, Read means fetching documents from a collection based on a condition. MongoDB finds documents — it does not select rows.

  • Verify inserts
  • Fetch user data
  • Power APIs
  • Prepare for updates and deletes

Prerequisite: Insert One Document for Practice

Step 1: Select the Database

use codinggita

Step 2: Insert One Student Document

db.students.insertOne({
  name: "Arjun",
  rollNumber: "CG101",
  department: "CSE",
  year: 3,
  coursesEnrolled: ["DBMS", "Data Structures", "Algorithms"],
  age: 22,
  registrationDate: new Date()
});
This single document is enough to practice find(), findOne(), and basic filters.

2. The find() Method

db.collectionName.find()

This command returns all documents in a collection. Results are returned in cursor format.

Example: Read All Students

db.students.find()

3. Reading with a Filter

db.collectionName.find({ field: value })

Example: Find Students from CSE

db.students.find({ department: "CSE" })
MongoDB matching is case-sensitive. "cse" is not equal to "CSE".

4. Using findOne()

db.collectionName.findOne()

Example

db.students.findOne({ rollNumber: "CG101" })
find() findOne()
Returns multiple documents Returns one document
Cursor Single object
Lists & collections Detail views

5. Understanding Query Matching

db.students.find({ year: 3 })
MongoDB is type-sensitive. Numbers and strings are not the same.

6. Reading Array Fields

db.students.find({ coursesEnrolled: "DBMS" })

MongoDB automatically checks array values. No special syntax is required.
